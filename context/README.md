# web-app-sdk-template context

web-app-sdk-template is the starting point for a web client: one template that builds two ways,
embedded, where Vite builds and Go embeds the output and serves it through go-web-sdk's
`NewClient`, and external, from `index.html`. It follows go-web-sdk-template's layout: a
`template/` subtree, `template/vX.Y.Z` tags, and a project generated by curl and tar from the tag's
tarball. Its check reports the shipped bundle's size and enforces no budget.

It is a package under the `@standards-lab` scope, starting at v0.1.0 and released by a plain
`vX.Y.Z` tag. Its goals live in the coordinator's roadmap (`standards-lab/context/roadmap.toml`,
v1.client.stack), and its strategy is `standards-lab/context/web-client.md`. It is seeded by copy
from spike-html-apps' app, with a provenance line on every copied file; the spike is archived and never a
dependency.

## Capability map

- **Template**: the `template/` subtree, on web-foundation, web-components, and web-app-sdk.
- **Embedded build**: Vite, then `//go:embed all:dist` served by `NewClient`.
- **External build**: a static `index.html` build.
- **Generation**: a project from a `template/vX.Y.Z` tarball by curl and tar.
- **Bundle report**: the shipped bundle's size, reported by the check.
